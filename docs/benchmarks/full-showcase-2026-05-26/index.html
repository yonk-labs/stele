The efficiency frontier

Every retrieval strategy plotted by answer accuracy against the tokens it spends (log scale). The prize is the top-left: high accuracy, low cost. digest — a lede summary + extracted facts + the top-5 chunks — lands there while raw context sprawls expensively to the right.

Accuracy, strategy by strategy

Same selector. Bars are answer accuracy; the number on the right is mean tokens. On real corpora, digest matches or beats full context at a fraction of the tokens — and on LongMemEval it actively denoises: 15k raw tokens score 0.50, a 1.5k digest scores 0.75.

Four engines, one contract

Payload reduction is identical across backends (96.57% — same content, same chunking). What changes is latency. The full path — intercept, store, scrub, summarize — stays in single-digit-to-low-double-digit milliseconds everywhere.

The field, in context

Published LoCoMo scores from other agentic-memory systems. These are not a leaderboard. Each was run under a different answer model (mostly GPT-4o / GPT-4o-mini), a different judge, and a different harness — the same system scores 58% → 75% depending on who runs it. stele's bar uses a fully local quantized Qwen answerer + an independent gemma judge, so it is not comparable to a GPT-4o-mini number — it's shown for honest placement, not victory.

⚠ Different LLMs · different judges · different harnesses · "J" means LLM-judge for some, Jaccard or F1 for others. Cross-vendor rankings only hold within one source's run. The only true comparison is re-running rivals in one harness — which scripts/run-full-showcase.sh is built to do.
LoCoMo · published LLM-judge score (claimed, see caveat)
Where stele genuinely stands out is LongMemEval — its digest packing scores 0.75 on a local answerer, above published GPT-4o-mini memory numbers (~0.60) and full-context baselines (~0.55–0.64). Even there, treat it as directional. Full sourced table + confounders: agentic-memory-comparison.md.
